# StudyPal & SkillConnect – Design Plan

## 1. Color Palette

The initial design uses a clean, modern, and student-friendly color palette.

| Purpose         | Color      | Hex Code  |
| --------------- | ---------- | --------- |
| Primary         | Blue       | `#2563EB` |
| Secondary       | Purple     | `#7C3AED` |
| Background      | Light Gray | `#F8FAFC` |
| Surface / Cards | White      | `#FFFFFF` |
| Text            | Dark Slate | `#1E293B` |
| Accent          | Cyan       | `#06B6D4` |

## 2. Typography

- **Headings:** Inter – bold and semibold weights.
- **Body Text:** Inter – regular weight.
- **Buttons and Labels:** Inter – medium weight.

Typography should remain readable, consistent, and accessible throughout the application.

## 3. Layout and Structure

### Navigation

- Responsive navigation bar.
- Project logo or application name.
- Links to Dashboard, Courses, Study Groups, and Profile.
- Mobile-friendly navigation.

### Dashboard

- Welcome message for the student.
- Overview of enrolled courses.
- Study group information.
- Quick access to important features.

### Cards

- Course cards display course information.
- Study group cards display group details and membership.
- Cards use consistent spacing, rounded corners, and subtle shadows.

### Responsive Design

- Mobile-first layout.
- Flexible grid system.
- Responsive navigation.
- Layout adapts to mobile, tablet, and desktop screens.

## 4. Design Goals

- Simple and intuitive navigation.
- Consistent visual styling.
- Accessible and readable content.
- Responsive user interface.
- Student-friendly experience.

## 5. Design Status

This document represents the initial proposed design direction for StudyPal & SkillConnect. The team may refine the colors, typography, and layout during project development.
