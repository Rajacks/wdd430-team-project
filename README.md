# StudyPal & SkillConnect

## WDD430 – Web Full-Stack Development Team Project

StudyPal & SkillConnect is a collaborative team project developed for WDD430 – Web Full-Stack Development at BYU-Idaho.

The application is designed to support students through student registration, course management, student profiles, course-based search, study group management, and student dashboards.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Rajacks/wdd430-team-project.git
```

Navigate to the project directory:

```bash
cd wdd430-team-project
```

Install dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Commands

| Command                | Description                          |
| ---------------------- | ------------------------------------ |
| `npm run dev`          | Starts the development server        |
| `npm run build`        | Builds the application               |
| `npm run start`        | Starts the production server         |
| `npm run lint`         | Runs ESLint                          |
| `npm run format`       | Formats project files using Prettier |
| `npm run format:check` | Checks Prettier formatting           |
